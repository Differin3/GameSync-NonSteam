## [0.3.1] — 2026-11-14

### Исправлено

- **Автосинхронизация не переживала перезапуск Decky**: флаг хранился только во
  фронтенде. Теперь он пишется в `~/.config/gamesync/settings.json` и монитор
  поднимается в `_main`.
- **Автосинхронизация игнорировала глобальные пути** — `_resolve_save_paths_for_game`
  теперь добавляет `default_save_paths` из настроек; фронтенд сохраняет их на бэкенде.
- **Блокирующий ввод-вывод в event loop**: сканирование игр, сборка архива и
  загрузка в облако перенесены в `asyncio.to_thread` — плагин не зависает.
- **Монитор процессов** синхронизировал игру при завершении любого Wine-процесса.
  Теперь он ждёт, пока закроется последний процесс игры, и игнорирует префикс `DEFAULT`.
- **Вложенные папки провайдеров**: `GameSync/<Игра>/` не создавалась, если не было
  родителя; WebDAV/FTP/SFTP создают папки по сегментам.
- **Статистика**: «Всего синхронизаций» показывало число игр, а не записей —
  теперь считает историю бэкапов.
- **Безопасность восстановления**: манифест из облака мог указать путь вне домашней
  папки; теперь цель проверяется на принадлежность `Path.home()`.
- **Недописанный архив** оставался на диске при ошибке сборки — удаляется.
- **Конкурентная запись** истории бэкапов — добавлена блокировка.
- **Вкладка «Бэкапы»** после восстановления показывала полноэкранный спиннер —
  список обновляется тихо, выбранная игра сохраняется.
- `sync_game` без `save_paths` падал с ошибкой — теперь определяет пути сам.
- WebDAV: таймаут загрузки/скачивания поднят с 60 до 300 секунд для больших архивов.

### Изменено

- Вкладка «Основные» читает состояние автосинхронизации и глобальные пути с бэкенда.
- Подсказка про автосинхронизацию больше не обещает сброс после перезапуска.
## [0.3.0] — 2026-11-14

### Добавлено

- **Восстановление сохранений**: вкладка «Бэкапы» в настройках, список версий,
  подтверждение и прогресс; бэкенд-методы `get_backups` и `restore_backup`.
- **Версии бэкапов**: каждый аплоад сохраняется как
  `GameSync/<Игра>/backup-<дата>.tar.gz`, стабильная копия `GameSync/<Игра>.tar.gz`
  остаётся для ручного доступа.
- **Манифест архива** `.gamesync/manifest.json` с исходными путями сохранений —
  без него восстановление невозможно.
- **История бэкапов** в `~/.config/gamesync/backups.json` (10 версий на игру).
- **Страховочная копия перед восстановлением** — `prerestore-<дата>.tar.gz`.
- Безопасная распаковка: запрет `..`, абсолютных путей, симлинков и устройств.
- Пресеты хранилищ вынесены в `src/utils/storagePresets.ts`: Облако Mail.ru по
  умолчанию, Яндекс Диск с предупреждением о подписке 360, Nextcloud/ownCloud,
  Fastmail; Box удалён (WebDAV отключён в 2023).
- Одна кнопка «Проверить и сохранить», автоопределение провайдера по URL.
- Unit-тесты бэкенда (`tests/`) и шаг тестов в CI.
- Документация: `docs/ARCHITECTURE.md`, `docs/API.md`, этот файл.

### Изменено

- Секреты больше не пишутся в `localStorage` — только в конфиг бэкенда (0600).
- `create_backup` формирует уникальные корни путей и манифест; формат архива v1.
- Провайдеры принимают `remote_name` в `upload_file`.
- `clear_all_data` очищает и историю бэкапов.
- README переписан под новые сценарии (RU/EN).

### Исправлено

- RPC-методы получали `dict` вместо значений: Decky передаёт аргументы позиционно.
  Добавлен декоратор `decky_params`; `sync_game`, `update_game_paths`,
  `validate_save_path`, `enable_auto_sync` и другие методы снова работают.
- `scan_games({})` больше не сбрасывает кэш на каждый вызов.
- CI: архив пересоздаётся (`rm -f` перед `zip -r`) — из сборки перестали попадать
  удалённые модули (`conflict_resolver.py`, `gdrive_provider.py`).
- Удалён каталог `примеры/` (копия OpenCloudSaves).
